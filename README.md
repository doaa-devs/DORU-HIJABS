# DORU HIJABS

### A Modern Hijab E-Commerce Website

DORU HIJABS is a web development project focused on creating an elegant and user-friendly online shopping experience for hijab products. The website combines a clean design with a simple and practical shopping interface.

## Project Overview

The goal of this project is to build a modern online store that presents hijab products in an organized and visually appealing way.

## Features

- Elegant and responsive website design.
- Product display with images.
- Interactive user interface.
- Shopping cart interface.
- Product details and modal windows.

## Technologies Used

- **HTML5** — Website structure.
- **CSS3** — Styling and layout.
- **JavaScript** — Interactive features and user interactions.

## Project Structure

- `index.html` — Main website page.
- `style.css` — Website styles and layout.
- `script.js` — Interactive functionality.
- Product images — Visual content for the store.
